# Gemini Clone (AI Chat App)
A responsive AI chat application inspired by Gemini, built using React.js. It supports real-time text interaction and voice input using the browser’s speech recognition API, and generates responses using Google AI Studio API.

This project is a frontend-based AI chatbot inspired by Gemini. It allows users to interact with an AI model through both text and voice input. The application integrates Google AI Studio API to generate intelligent responses.

One of the key features of this project is voice input support, where users can click on the microphone icon and speak their query. The speech is converted into text using the Web Speech API and processed to generate responses.

The UI is clean and responsive, designed using modern frontend technologies.

✨ Features
💬 Real-time AI chat interface
🎤 Voice input (Speech-to-Text)
⚡ Fast and responsive UI
🔁 Dynamic message rendering
📱 Fully responsive design
🔐 API integration with Google AI Studio


🛠️ Tech Stack
HTML
CSS
React.js
JavaScript
Web Speech API (for voice input)
Google AI Studio API (for AI responses)


🧠 Key Learnings
Handling API integration in React
Working with browser-based speech recognition
Managing component state effectively
Fixing production issues (like asset path errors in deployment)
Deploying React apps on Vercel
